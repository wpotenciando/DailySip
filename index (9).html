auto‑publish to github

Paste a GitHub token once. After that, tapping Save updates your site automatically. The token is stored encrypted with your developer password, on this device only.

How to get a token
  1. On GitHub open Settings → Developer settings → Personal access tokens → Fine‑grained tokens and press Generate new token.
  2. Under Repository access choose Only select repositories and pick your site’s repository.
  3. Under Permissions → Repository permissions set Contents to Read and write.
  4. Generate the token, copy it (it starts with github_pat_) and paste it above.
  5. In the repository, open Settings → Pages and publish from the main branch, root folder.
